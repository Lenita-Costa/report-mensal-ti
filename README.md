# Report Mensal de TI — Fenasbac

Panoramas mensais de Tecnologia consolidados para a visão de Diretoria.
Coordenação de TI · Diretoria de Inovação.

## Dashboard

O painel do mês corrente é publicado via GitHub Pages:

**https://lenita-costa.github.io/report-mensal-ti/**

`index.html` na raiz é sempre uma cópia do painel do mês mais recente.

## Estrutura

```
index.html                 painel do mês corrente (publicado no Pages)
agosto-2026/
  painel-estrategico-ti-agosto-2026.html   painel do mês (original)
  Report_Mensal_TI_Agosto_2026.docx        report em documento
```

## Meses publicados

| Mês | Sprints | Painel | Documento |
|---|---|---|---|
| Agosto/2026 | S16 · S17 (04/08 a 31/08) | [painel](agosto-2026/painel-estrategico-ti-agosto-2026.html) | [.docx](agosto-2026/Report_Mensal_TI_Agosto_2026.docx) |

## Como adicionar um novo mês

1. Criar a pasta do mês (ex.: `setembro-2026/`) com o painel e o `.docx`.
2. Copiar o novo painel para `index.html` na raiz.
3. Adicionar a linha na tabela acima.
4. Commit e push na `main` — o Pages atualiza automaticamente.

## Observação

Este repositório é público, portanto o painel e o documento ficam acessíveis
na internet por quem tiver o link. O conteúdo é executivo (indicadores,
marcos e frentes de trabalho); não inclui dados pessoais, credenciais ou
informação de acesso.

Os relatórios quinzenais por sprint seguem em
[relatorio-sprint](https://github.com/Lenita-Costa/relatorio-sprint).
